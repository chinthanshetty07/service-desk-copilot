title: Connect to the company VPN
category: Network
automation:
---
Use this when the VPN client fails to connect, disconnects repeatedly, or shows an authentication error.

Resolution steps:
1. Check the user is on a working internet connection by opening any public website.
2. Update the VPN client to the latest version from the software portal.
3. Sign in with the company email and approve the MFA prompt.
4. If the error says "certificate expired", restart the laptop so the device certificate renews.
5. If many users report VPN failures at once, raise a P1 incident for the network team.
