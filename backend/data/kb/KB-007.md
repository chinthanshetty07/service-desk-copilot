---
id: KB-007
title: Request access to a shared mailbox, folder or distribution list
category: Access & Identity
automation: access_request
---
Use this when someone needs access to a shared mailbox, a shared drive folder, or a distribution list.

Resolution steps:
1. Record exactly which mailbox, folder or list is needed and the level of access (read or edit).
2. Send the request to the resource owner or the employee's manager for approval.
3. After approval, add the user to the access group; changes can take up to 60 minutes to apply.
4. Ask the user to restart Outlook or the file sync app.

Automation: access can be granted automatically once the owner approves in the portal.
