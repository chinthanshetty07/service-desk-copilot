---
id: KB-005
title: Wi-Fi connected but no internet in the office
category: Network
automation:
---
Use this when a laptop shows it is connected to office Wi-Fi but pages do not load.

Resolution steps:
1. Forget the office network and reconnect, accepting the sign-in page if shown.
2. Turn airplane mode on and off, or restart the laptop.
3. Try the wired dock or the guest network to check whether the issue is the device or the network.
4. If a whole floor is affected, report it as a network outage with the floor and time.
