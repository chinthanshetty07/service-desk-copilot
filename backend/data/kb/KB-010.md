id: KB-010
title: Request installation of new software
category: Software
automation: software_request
---
Use this when someone needs an application that is not already on their laptop.

Resolution steps:
1. Check the self-service software portal; approved apps install without a ticket.
2. For apps not in the portal, record the app name, version and business reason.
3. Paid licences need manager approval before purchase.
4. Security reviews new apps before installation; this can take up to five working days.

Automation: apps in the approved catalogue can be pushed automatically to the laptop.
